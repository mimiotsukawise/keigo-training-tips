# 敬語トレーニングクイズ

敬語の決まりや使い方を、クイズ形式で楽しく学ぶためのWebアプリです。

## アプリの概要

ユーザーに敬語のクイズをランダムに出題し、回答後に正解・不正解と解説を表示します。最初は20問から始め、将来は100問程度まで追加できる構成を目指します。

主な問題形式は次の3種類です。

- Yes / No形式
- 選択肢から答えるマルチプルチョイス形式
- 表現を正しい敬語に直す入力形式

## 回答の流れ

1. クイズをランダムに1問表示します。
2. ユーザーが回答すると、正解または不正解を表示します。
3. 正解の場合は、「次のクイズへ」ボタンを表示します。
4. 不正解の場合は、「やり直す」と「答えを見る」を表示します。
5. 「やり直す」を選ぶと、同じ問題の最初の画面へ戻ります。
6. 「答えを見る」を選ぶと、正解と解説を表示し、「次のクイズへ」ボタンを表示します。

## デザイン

- 緑を基調にした、明るくかわいらしいデザイン
- 日本を象徴するイメージやモチーフを使用
- パソコンとスマートフォンのどちらでも使いやすい画面
- 正解、不正解、次の操作が分かりやすい表示

## 問題データ

問題データはアプリの画面コードから分けて管理し、問題を追加しやすくします。各問題には、問題ID、問題文、問題形式、選択肢、正解、解説などを登録します。

参照資料は問題データには含めず、問題を作成・確認するための資料として `docs/references/` で別に管理します。
