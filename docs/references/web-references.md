## 「御社」と「貴社」の違いは？メール・面接での使い分けや「弊社」「当社」との違いも解説

- 提供元：マイナビ転職
- URL：https://tenshoku.mynavi.jp/knowhow/caripedia/20/
- 更新日：2025年7月9日
- 参照日：2026年8月10日
- 主な内容：
  - 相手の会社を表す「御社」と「貴社」の使い分け
  - メールなどの書き言葉では「貴社」、面接や電話などの話し言葉では「御社」を使うという整理
  - 自社を表す「弊社」と「当社」の使い分け
  - 「御中」と「様」の使い分けと、両者を重ねないという注意
  - 敬称を重ねる二重敬語・二重敬称への注意
- このプロジェクトでの用途：顧客メールにおける自社・相手企業・宛名の表現を扱う問題の確認資料

- URL：https://www.callconnect.jp/blog/61
- 参照日：2026年8月10日

  - コールセンターで使われる丁寧語・尊敬語・謙譲語
