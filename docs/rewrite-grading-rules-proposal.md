# 記述式問題の採点ルール案

## 1. この文書の目的

記述式9問について、機械学習やAIを使わず、問題ごとに明示したルールで採点するための確認用設計書です。

この段階では採点プログラムへ組み込みません。必要な表現、不正解になる表現、テスト回答の妥当性を確認した後に実装します。

## 2. 共通の判定順序

1. 空白、改行、句読点、全角・半角など、敬語の正しさに影響しない表記ゆれを整えます。
2. 登録済みの正解文と一致した場合は正解とします。
3. 問題固有の不正解表現が含まれる場合は不正解とします。
4. 問題固有の必要表現グループをすべて満たす場合は正解とします。
5. 必要表現が不足する場合は不正解とします。

不正解表現の判定を必要表現より先に行い、正しい語句と誤った敬語が混在する回答を正解にしないようにします。

### クッション言葉の扱い

依頼、質問、お断りなどの文章では、次のクッション言葉を文頭に加えても、本文が各問題の必要表現を満たしていれば正解とします。

- `恐れ入りますが／誠に恐れ入りますが／大変恐れ入りますが`
- `恐縮でございますが／誠に恐縮でございますが／大変恐縮でございますが`
- `差し支えなければ`
- `お手数をおかけいたしますが／誠にお手数をおかけいたしますが／大変お手数をおかけいたしますが`
- `申し訳ございませんが／誠に申し訳ございませんが／大変申し訳ございませんが`

クッション言葉が付いていても、本文に問題固有の禁止表現が含まれる場合は不正解とします。

## 3. q02：名前を尋ねる

元の文章：`確認のため、お名前を頂戴してもよろしいでしょうか。`

### 必要な表現

- 対象：`名前`または`お名前`
- 名前を尋ねる表現：次のいずれか
  - `伺ってもよろしいでしょうか`
  - `伺ってもよろしいですか`
  - `お聞かせいただけますか／でしょうか`
  - `教えていただけますか／でしょうか`
  - `お知らせいただけますか／でしょうか`

### 不正解になる表現

- `名前を頂戴`
- `お名前をお伺い`
- `名前を伺われ`

### 正解テスト例

1. 確認のため、お名前を伺ってもよろしいですか。
2. お名前を教えていただけますでしょうか。
3. 確認のため、お名前をお聞かせいただけますか。
4. お名前をお知らせいただけますでしょうか。
5. 恐れ入りますが、お名前を伺ってもよろしいでしょうか。

### 不正解テスト例

1. お名前を頂戴してもよろしいでしょうか。
2. お名前をお伺いしてもよろしいでしょうか。
3. お名前を伺われてもよろしいでしょうか。
4. 確認のため、お名前をお願いします。
5. お名前を確認いたします。

## 4. q03：お客様によるサービス利用

元の文章：`弊社のサービスをご利用される場合は、本人確認が必要です。`

### 必要な表現

- 対象：`サービス`
- 利用条件：次のいずれか
  - `ご利用になる場合／際`
  - `利用される場合／際`
  - `お使いになる場合／際`
  - `ご利用の場合／際`
- 必要事項：`本人確認`と`必要`

### 不正解になる表現

- `ご利用される`
- `ご利用になられる`
- `利用いたす`（お客様の行為として使用した場合）

### 正解テスト例

1. 弊社のサービスをご利用になる場合は、本人確認が必要です。
2. 弊社のサービスを利用される際は、本人確認が必要です。
3. 弊社のサービスをお使いになる場合、本人確認が必要です。
4. 弊社サービスのご利用には、本人確認が必要です。
5. 当サービスをご利用の場合は、本人確認が必要となります。

### 不正解テスト例

1. 弊社のサービスをご利用される場合は、本人確認が必要です。
2. 弊社のサービスをご利用になられる際は、本人確認が必要です。
3. お客様が弊社のサービスを利用いたす場合は、本人確認が必要です。
4. 弊社のサービスをご利用になる場合があります。
5. 本人確認が必要です。

## 5. q04：お客様が書類を提出できないことを伝える

元の文章：`ファイルサイズが大きい場合は、書類をご提出できません。`

### 必要な表現

- 条件：`ファイルサイズ`と`大きい`
- 対象：`書類`と`提出`
- 提出できないこと：次のいずれか
  - `ご提出いただけません`
  - `ご提出いただくことができません`
  - `提出できません`
  - `提出することができません`

### 不正解になる表現

- `書類をご提出できません`
- `書類をご提出いたしかねます`（お客様の行為として使用した場合）
- 提出可能であることを示す`提出できます／ご提出いただけます`

### 正解テスト例

1. ファイルサイズが大きい場合、書類をご提出いただけません。
2. ファイルサイズが大きい場合は、書類をご提出いただくことができません。
3. ファイルサイズが大きいと、書類を提出できません。
4. 書類は、ファイルサイズが大きい場合には提出することができません。
5. ファイルサイズが大きすぎる場合、書類をご提出いただけません。

### 不正解テスト例

1. ファイルサイズが大きい場合は、書類をご提出できません。
2. ファイルサイズが大きい場合、お客様は書類をご提出いたしかねます。
3. ファイルサイズが大きい場合でも、書類をご提出いただけます。
4. ファイルサイズが大きい場合は、書類を確認できません。
5. 書類をご提出いただけません。

## 6. q06：お客様の意見を社内へ伝える

元の文章：`いただいたご意見は、担当部署にお伝えします。`

### 必要な表現

- 対象：`意見`または`ご意見`
- 伝達先：`担当部署`または`関係部署`
- 自社内への伝達：`申し伝えます／申し伝えいたします`

### 不正解になる表現

- `担当部署にお伝えします`
- `担当部署へお伝えいたします`
- `担当部署に申し上げます`

### 正解テスト例

1. いただいたご意見は、担当部署に申し伝えます。
2. お寄せいただいたご意見を、担当部署へ申し伝えます。
3. いただきましたご意見は、関係部署に申し伝えいたします。
4. 貴重なご意見として、担当部署に申し伝えます。
5. ご意見につきましては、担当部署へ確かに申し伝えます。

### 不正解テスト例

1. いただいたご意見は、担当部署にお伝えします。
2. ご意見を担当部署へお伝えいたします。
3. いただいたご意見は、担当部署に申し上げます。
4. 担当部署がご意見を申し伝えます。
5. いただいたご意見を確認いたします。

## 7. q09：住民票の提出を案内する

元の文章：`本人確認書類がない場合は、住民票をご提出いただく形になります。`

### 必要な表現

- 条件：`本人確認書類`と`ない／お持ちでない／用意できない`
- 必要書類：`住民票`
- 依頼または必要性：次のいずれか
  - `ご提出いただく必要がございます／あります`
  - `ご提出をお願いいたします`
  - `ご提出くださいますようお願いいたします`
  - `ご提出ください`
  - `ご用意ください`

### 不正解になる表現

- `提出いただく形になります`
- `ご提出になる形になります`
- `住民票を提出させていただきます`（お客様に提出を依頼する文脈）

### 正解テスト例

1. 本人確認書類がない場合は、住民票をご提出いただく必要があります。
2. 本人確認書類をお持ちでない場合は、住民票のご提出をお願いいたします。
3. 本人確認書類をご用意できない場合、住民票をご提出ください。
4. 本人確認書類がない場合は、住民票をご提出くださいますようお願いいたします。
5. 本人確認書類をお持ちでない場合には、住民票をご用意ください。

### 不正解テスト例

1. 本人確認書類がない場合は、住民票をご提出いただく形になります。
2. 本人確認書類がない場合は、住民票をご提出になる形になります。
3. 本人確認書類がない場合は、住民票を提出させていただきます。
4. 住民票をご提出ください。
5. 本人確認書類がない場合は、住民票を確認いたします。

## 8. q12：メールを確認したか尋ねる

元の文章：`先ほどお送りしたメールは、ご確認になられましたでしょうか。`

### 必要な表現

- 対象：`メール`
- お客様による確認：次のいずれか
  - `ご確認いただけましたか／でしょうか`
  - `ご覧いただけましたか／でしょうか`
  - `ご確認になりましたか／でしょうか`
  - `ご覧になりましたか／でしょうか`

### 不正解になる表現

- `ご確認になられ`
- `ご覧になられ`
- `拝見され`
- `拝見いただけ`（お客様の行為として使用した場合）

### 正解テスト例

1. 先ほどお送りしたメールは、ご確認いただけましたか。
2. 先ほどお送りしたメールをご覧いただけましたでしょうか。
3. 先ほどのメールはご確認になりましたでしょうか。
4. お送りしたメールをご覧になりましたか。
5. 先ほど送付いたしましたメールは、ご確認いただけましたでしょうか。

### 不正解テスト例

1. 先ほどお送りしたメールは、ご確認になられましたでしょうか。
2. 先ほどのメールをご覧になられましたか。
3. 先ほどお送りしたメールを拝見されましたか。
4. 先ほどのメールを拝見いただけましたでしょうか。
5. 先ほどメールをお送りいたしました。

## 9. q13：お客様が話した内容を示す

元の文章：`先ほどお客様がおっしゃられた内容について確認いたしました。`

### 必要な表現

- お客様が話した内容：次のいずれか
  - `お客様がおっしゃった内容`
  - `お客様がお話しになった内容`
  - `お客様がご説明くださった内容`
  - `お客様から伺った内容`
- 自分側の確認：`確認いたしました／確認しました`

### 不正解になる表現

- `おっしゃられ`
- `お話しになられ`
- `伺われた`（お客様が話した意味で使用した場合）

### 正解テスト例

1. 先ほどお客様がおっしゃった内容を確認いたしました。
2. お客様がお話しになった内容について確認しました。
3. 先ほどお客様がご説明くださった内容を確認いたしました。
4. 先ほどお客様から伺った内容について確認しました。
5. お客様より先ほど伺いました内容を確認いたしました。

### 不正解テスト例

1. 先ほどお客様がおっしゃられた内容について確認いたしました。
2. お客様がお話しになられた内容を確認しました。
3. お客様が伺われた内容について確認いたしました。
4. 先ほどお客様がおっしゃった内容です。
5. 先ほど確認した内容をお客様がおっしゃいました。

## 10. q15：自社担当者からの連絡を案内する

元の文章：`弊社の担当者から、お客様へご連絡されます。`

### 必要な表現

- 自社側の人物：`弊社の担当者／弊社担当者／担当者`
- お客様への連絡：次のいずれか
  - `ご連絡いたします`
  - `ご連絡申し上げます`
  - `連絡いたします`

### 不正解になる表現

- `担当者からご連絡されます`
- `担当者がご連絡なさいます`
- `担当者からのご連絡になります`
- `担当者にご連絡いただきます`（自社から連絡する案内として使用した場合）

### 正解テスト例

1. 弊社の担当者から、お客様へご連絡いたします。
2. 弊社担当者より、改めてご連絡申し上げます。
3. 担当者が後ほどご連絡いたします。
4. 弊社の担当者より、お客様へ連絡いたします。
5. 後ほど担当者から改めてご連絡いたします。

### 不正解テスト例

1. 弊社の担当者から、お客様へご連絡されます。
2. 弊社担当者がご連絡なさいます。
3. 担当者からのご連絡になります。
4. 弊社の担当者にご連絡いただきます。
5. お客様から担当者へご連絡いただきます。

## 11. q19：担当者への問い合わせを案内する

元の文章：`ご不明な点がございましたら、担当者にお伺いください。`

### 必要な表現

- 条件：`不明／ご不明／不明点／質問`
- 問い合わせの案内：次のいずれか
  - `お尋ねください`
  - `お問い合わせください`
  - `ご連絡ください`
  - `お申し付けください`

### 不正解になる表現

- `お伺いください`
- `伺ってください`
- `伺われてください`
- `問い合わせさせていただいてください`

### 正解テスト例

1. ご不明な点は、担当者までお問い合わせください。
2. 不明点がございましたら、担当者へお尋ねください。
3. ご不明な点がある場合は、担当者までご連絡ください。
4. ご質問がございましたら、担当者へお問い合わせください。
5. ご不明点がございましたら、担当者までお申し付けください。

### 不正解テスト例

1. ご不明な点がございましたら、担当者にお伺いください。
2. 不明点がある場合は、担当者に伺ってください。
3. ご質問は担当者に伺われてください。
4. ご不明な点は、担当者が問い合わせます。
5. 担当者までご連絡いたします。

## 12. 承認された判定方針

- q02：`お名前をお伺いする`は不正解とします。
- q03：`ご利用される`は不正解とします。
- q04：`書類を提出できません`は正解とします。
- q09：`住民票をご用意ください`は正解とします。
- q12：`ご確認になりましたでしょうか`は正解とします。
- q19：本書に記載したルール案のままとします。
